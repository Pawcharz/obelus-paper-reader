## What's new in 0.3.1

- **Settings looked broken on smaller screens.** With the new "Reading on this computer" section, the Settings window could squash the handwriting-languages list and draw it over the section below. The window now scrolls instead.
- **The settings folder is now named after the app:** `%APPDATA%\Obelus` (Linux: `~/.config/Obelus`) instead of `paper-reader`, and the preview cache `%LOCALAPPDATA%\Obelus` instead of `PaperReader`. On its first start, 0.3.1 moves the old folders there, so your library, sign-in, downloaded models and reading positions all stay. After updating, don't start an older version: it would not find them and would open empty.

Everything else is as in [0.3.0](https://github.com/Pawcharz/obelus-paper-reader/releases/tag/v0.3.0): handwritten maths read on your computer, handwriting on Linux, optional Google sign-in, HTML reports.
