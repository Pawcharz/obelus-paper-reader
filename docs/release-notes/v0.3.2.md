## What's fixed in 0.3.2

- **Scanned papers showed blank pages.** Older papers that are scans, such as journal articles from the 1970s, often store each page as a compressed black-and-white image (JBIG2, or JPEG 2000). Obelus didn't ship the decoder for those images, so the pages came out white, with only highlights or links drawn on top. The decoder is now included, and such papers open normally on Windows and Linux. Thanks for the report!

Nothing else changed since [0.3.1](https://github.com/Pawcharz/obelus-paper-reader/releases/tag/v0.3.1). If you're updating from 0.3.0 or older, read its notes too: the settings folder moved to `%APPDATA%\Obelus` (Linux: `~/.config/Obelus`) and is moved there automatically.
